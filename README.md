# Affektions-Gacha

A daily capsule-pull PWA for Lennart and Fionn — served straight from GitHub Pages. Lennart taps the 3D-printed gacha machine (NFC), the page shows one deterministic result per day: blanks, mini-quests, rare date-credits, photo drops, and jackpots. Fionn gets a parallel view at the same URL with `?player=fionn`.

## How it works

The result is computed deterministically from three things:

- `machine.secret` in `config/theme.json`
- Today's date in `Europe/Zurich`
- The `?token=` URL parameter (defaults to `lennart`)

Same day → same result. Refreshing never re-rolls. Tomorrow gets a new pull automatically.

Fionn's view is loaded via `?player=fionn`. It shows the same full UI but with Fionn's name, Fionn's daily mission, and the send button pointing to Lennart.

Everything editable lives in `config/`. Use the GitHub web editor (pencil icon) and commit directly to `main`. GitHub Actions validates automatically.

| File | What to edit |

| Parameter | Example | Effect |
|---|---|---|

## Special days

Add entries to `config/special-days.json` to override the random draw on specific dates.

**Date formats:**

| Format | Matches |
|---|---|
| `"MM-DD"` | Every year (e.g. birthday) |
| `"YYYY-MM-DD"` | One specific date |

**Example:**

```json
{
  "days": [
    {
      "date": "05-29",
      "label": "Geburtstag 🎂",
      "tone": "jackpot",
      "outcomes": [
        {
          "title": "Alles Gute zum Geburtstag!",
          "message": "Heute ist dein Geburtstag – die Maschine hat extra für dich gewürfelt."
        }
      ],
      "colors": {
        "primary": "#c8860a",
        "gold": "#e8a020",
        "background": "#fffbf0"
      }
    }
  ]
}
```

**Fields:** `date` (required), `label` (required), `outcomes` (required), `tone` (optional, default `"jackpot"`), `colors` / `darkColors` (optional — override any palette key).

Available color keys: `background`, `surface`, `surfaceAlt`, `text`, `muted`, `border`, `primary`, `primaryDark`, `gold`, `green`, `blue`, `sky`, `mountain`.

## Photo & video drops

Photos and videos appear when the `Foto-Drop` category is drawn (~23% base chance).

**`config/photos.json` entry:**

```json
{
  "url": "https://example.com/foto.jpg",
  "alt": "Wir beim Kaffee",
  "caption": "Beweisstück A: ziemlich süß.",
  "type": "image"
}
```

`type` can be `"image"` (default) or `"video"`. Videos render as `<video controls muted playsinline>`.

Photos are displayed in a framed stage with blurred backdrop; the stage adapts its aspect ratio automatically (portrait 3:4, landscape 4:3, square 1:1).

Preview all media: [`media-preview.html`](media-preview.html)

## Auto-sync from a shared album

The gacha can pull its photo pool from a public iCloud or Google Photos album automatically.

1. Edit `config/album-source.json`:
   - `enabled`: `true`
   - `url`: public iCloud (`https://www.icloud.com/sharedalbum/#TOKEN`) or Google Photos link
   - `provider`: `"icloud"`, `"google"`, or `"auto"`
   - `videoMinDurationMs`: minimum clip length in ms before a video is treated as a real video (default **3 000 ms / 3 s**). Set higher to exclude short clips or Live Photos.
2. Run locally: `npm run sync:album`  
   Or on GitHub: **Actions → Sync shared album → Run workflow**

The workflow runs every **2 hours** on a cron schedule (`17 */2 * * *` UTC) and commits only `config/photos.json` back to the repo. iCloud CDN URLs expire ~3 hours after generation, so the 2-hour cadence keeps photos fresh.

**Privacy note:** Public shared albums are visible to anyone with the link.

## Bärlauch game & leaderboard

A hidden mini-game opened by the **Bärlauch** chip. A field of emoji fills the panel — good plants (🌿 🌱 🍃 🍀) mixed with bad ones (☠️ 🥀 🌸 🧄). A countdown timer ticks down and the field gradually darkens.

**Goal:** tap every good plant before time runs out without touching a bad one.

- **Win:** all good plants collected → a random photo appears with a sweet message, and a **Level N starten** button lets you continue. A new personal best triggers **confetti**.
- **Fail (timeout):** the field goes dark.
- **Fail (bad plant):** instant end.

**Leaderboard** appears after each round (win or lose), showing the last 10 rounds with date, player name (Du / Fionn), and result (✓ Level N or ✗). Best scores sync to the shared Google Sheet so both players see each other's records.

The game has **10 levels** — each level adds more bad plants, reduces time, and speeds up the animation. The level resets on page reload.

## Daily missions

A paired mission system — every day both Lennart and Fionn get a different task from the same pair, seeded by date. They don't see each other's mission until they talk.

- **Mission chip**: opens the mission panel showing today's task.
- **Erledigt ✓**: marks the mission done, saves it to the local log, syncs to the Google Sheet.
- **Feedback**: after marking done, an optional emoji rating (🔥 / 👍 / 😴) + comment can be sent.
- **Verlauf**: the mission panel shows a rolling log of both players' missions (sourced from the shared Google Sheet after sync).

Edit pairs in `config/missions.json`:

```json
{
  "pairs": [
    {
      "lennart": "Schreib drei Dinge auf, die du heute gut gemacht hast.",
      "fionn": "Schreib drei Dinge auf, die du heute gut gemacht hast."
    }
  ]
}
```

## Wunschkapsel inbox & backup (Google Sheet)

All data is backed up to a Google Sheet via a Google Apps Script web app.

**Sheet:** [Affektions-Gacha Sheets](https://docs.google.com/spreadsheets/d/1j21UmMS7g_uahk_y2BmWnStPkj6gcWUFfKWuFQBsEy4/edit)

Worksheets:
| Sheet | Contents |
|---|---|
| `Backup` | One row per player: favourites, streak, tokens, quest points |
| `History` | One row per gacha pull |
| `Wünsche` | Wunschkapsel submissions |
| `MissionLog` | One row per completed mission (day + player + rating) |
| `MissionFeedback` | Append-only feedback rows |
| `BaerlauchScores` | Best Bärlauch level per player |
| `Quests` | Quest solve log |

Setup:

1. Open [script.google.com](https://script.google.com) and create a new project.
2. Paste `scripts/backup-apps-script.js` into `Code.gs`.
3. **Deploy → New deployment → Web app**: Execute as *Me*, Who has access *Anyone*.
4. Copy the `…/exec` URL into both `config/wish-inbox.json` and `config/backup.json` → `endpointUrl`, set `enabled: true`. Commit + push.

After editing the script, always **redeploy** (Deploy → Manage deployments → ✏️ → Version: New version → Deploy). The `/exec` URL stays the same.

## 3D print notes

**Design file:** [Autodesk Fusion 360 — Gacha machine](https://a360.co/4uNxWSR)

- NFC sticker: NTAG215 or NTAG216, 25 mm
- Keep NFC under 1–2 mm of plastic; don't place directly behind metal
- Test before sealing
- For a coin: two-part press-fit capsule
- For a mini gacha machine: NFC behind the front window or the button
